🔥 COMMUNITY POST #2: RAG and AI Agent Developers (23.6k members)

Apps and agents both retry. In my pharmacy billing app, returns are idempotent: if the same return arrives twice, the second finds the first and stops. One ledger row, stock back to the same batch, the bill changes once. Any agent tool that writes deserves the same rule.
